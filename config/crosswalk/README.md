# config/crosswalk — 1차↔2차 유형 대응 확정본

module3(공간중첩)이 만든 **대응표 초안**을 사람이 검토·확정하는 자리입니다.
확정본은 이후 모듈5(변화탐지)에서 두 시점을 같은 비교단위로 재라벨하는 데 쓰입니다.

## 파일
- `crosswalk_중분류_확정.csv` — **주 대응표**(변화통계 비교의 기준)
- `crosswalk_대분류_확정.csv` — 참고용 상위 대응

원본 초안·교차표·히트맵: `outputs/20260703/`

## 컬럼
| 컬럼 | 의미 |
|---|---|
| 1차유형 | 2019년 1차 유형 |
| 초안_2차대응(지배) | module3가 면적기준으로 자동 추천한 지배 대응(참고) |
| 대응비율% / 1차총면적_ha | 지배대응 신뢰의 근거 |
| 신뢰도 | 상(≥70%) / 중(45~70%) / 하(<45%) |
| **확정_2차유형** | ← 사람이 확정하는 2차 유형(빈칸=검토 대기) |
| **비교그룹코드** | ← 1차·2차를 묶는 공통 비교단위. 여러 유형을 한 그룹으로 묶어 비교하려면 같은 코드를 부여 |
| 확정여부(Y/N) | 검토 완료 표시 |
| 검토메모 | 판단 힌트/주의 |

## 작성 규칙
1. `신뢰도=상` 행은 초안값으로 **미리 채워** 두었음 → 확인 후 그대로 두거나 수정.
2. `중/하` 행은 빈칸 → **교차표(중분류)와 히트맵**을 보고 확정.
   - **1:다 세분화**(예: 녹지 및 오픈스페이스)는 `비교그룹코드`를 같게 주어 여러 2차 유형을 한 그룹으로 묶어 비교.
   - 표본 극소 행(예: 상업 및 업무시설 1.2ha)은 무시하거나 인접유형에 흡수.
3. 모든 행 확정 후 `확정여부(Y/N)`를 Y로.

## 검토 우선순위(중분류)
- 🔴 **녹지 및 오픈스페이스** (60,678 ha, 최대비중) — 그룹핑 결과가 변화탐지 정확도를 좌우.
- 🔴 나지, 🟡 하천 및 호소 — 병합/확정 판단 필요.
