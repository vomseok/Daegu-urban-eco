# 도시생태현황도 기반 반복형 공간분석 시스템 — 가공·분석 설계 초안

작성일: 2026-06-29 / 대상지: 대구광역시 / 시점: 1차(2019), 2차(2024~25)

---

## 1. 전체 흐름 (한 번에 도는 파이프라인)

```
[단계0] 자동 탐색·진단   폴더 스캔 → 파일 카탈로그(목록·좌표계·필드·유형코드) 자동 작성
        │
[단계1] 가공(전처리)     ① 좌표계 통일  ② 속성 정제(라벨·결측·인코딩)  ③ 유형체계 표준화
        │
[단계2] 분석 (모듈 6종)  필요한 자료만 골라 모듈별 분석
        │
[단계3] 출력            주제도 · 통계표(엑셀) · 보고서(워드/PDF) · 대시보드
        │
[단계4] 해석            지표 요약·변화 진단·우선순위 표 자동 서술
```

**"반복 사용형"의 핵심**: 단계0의 카탈로그와 단계1의 표준화 규칙(대응표)을 한 번 만들어 두면,
새 자료(다른 연도·다른 시·군)를 폴더에 넣고 다시 실행하면 같은 규칙으로 자동 처리됩니다.

## 4. 단계1-③ 유형체계 표준화 (모듈3, 핵심 난제)

**문제**: 1차(U/B/C 4단계)와 2차(유형/피복/이용 3단계)는 분류 축·단계·라벨이 다름.

**접근 (데이터 주도 — 표준유형표에 맞추지 않음)**:
> 환경부 표준유형표는 실제 자료 적용 방식과 달라 대응에 도움이 안 됨(사용자 확인).
> 목표는 국가표준 준수가 아니라 **1차↔2차를 서로 비교 가능하게** 만드는 것.

1. **공간중첩(1순위)** — 1차·2차 폴리곤을 겹쳐(intersection) **같은 위치에서 어떤 1차 유형이 어떤 2차 유형과 만나는지** 교차표(면적 기준)를 만든다. 지배적 대응이 곧 대응관계.
2. **라벨/의미 유사도(보조)** — 공간중첩으로 애매한 것만 문자 유사도·동의어로 후보 추천.
3. **사람 확정** — 자동 대응표 초안을 사용자(도메인 전문가)가 검토·확정.

**비교 레벨**: 대/중/소 중 **데이터가 안정적으로 대응되는 레벨**을 경험적으로 선택(중분류 유력). 소분류는 시점 간 흔들림이 커 통계 비교엔 부적합할 수 있음.

**결과물**: 1차↔2차 **직접 대응표** + 공통 비교코드. 두 시점을 이 코드로 재라벨 → 시계열 통계·변화탐지 가능.

## 6. 출력 (공통 엔진)

- **주제도**: matplotlib(정적 PNG) + folium(웹 인터랙티브)
- **통계표**: openpyxl로 엑셀(.xlsx) — 모듈별 시트
- **보고서**: python-docx로 워드 → PDF 변환(지도·표·자동서술 포함)
- **대시보드**: streamlit + folium — 지도·필터·통계 한 화면

## 7. 구축 순서 (로드맵)

1. **단계0 자동화**: 폴더 스캔 → 카탈로그 생성기 (`src\catalog.py`)
2. **단계1 가공**: 좌표계 통일 + 속성 정제 함수
3. **모듈3 표준화**: 대응표·매칭 (가장 먼저 — 다른 모듈의 토대)
4. **모듈5 변화탐지** → **모듈4 연결성** → **모듈1 산림재해** → **모듈2 탄소** → **모듈6 우선지역**
5. **출력 엔진** 공통화 → **대시보드**

> 먼저 단계0 카탈로그 생성기부터 만들어 "자동 탐색·진단"을 코드로 고정하고,
> 그 위에 모듈3(표준화)을 올리는 순서를 추천합니다.
