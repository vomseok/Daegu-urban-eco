그늘로 (Geuneul) - Windows 사용 설명서
================================================================================

🎯 준비 단계 (처음 1회만)
================================================================================

1. 두 개의 배치 파일 다운로드:
   - 백엔드시작.bat
   - 앱시작.bat

2. 파일들을 "데스크톱"에 저장하세요

3. 각 파일을 메모장으로 열기:
   - 백엔드시작.bat를 마우스 우클릭 → "편집"
   - 첫 번째 줄에서 경로 확인:

     현재: C:\Users\당신이름\Desktop\Daegu-urban-eco

     자신의 프로젝트 폴더 경로로 수정하세요!

   - 같은 방식으로 앱시작.bat도 수정
   - 저장

================================================================================
🚀 사용법 (매번 할 때마다)
================================================================================

순서 1: 백엔드 서버 시작
--------
1. 데스크톱에서 "백엔드시작.bat" 더블클릭
2. 검은 창(터미널)이 열려요
3. 다음 문구가 보일 때까지 기다립니다:

   "INFO: Application startup complete"

4. ⚠️ 이 창을 닫지 마세요! (그대로 열어두기)

순서 2: 앱 실행
--------
1. 새로운 데스크톱에서 "앱시작.bat" 더블클릭
2. 또 다른 검은 창이 열려요
3. "선택해주세요" 메시지가 나타나면:

   1 또는 2 입력 후 엔터
   (1=Chrome 웹브라우저, 2=Android 에뮬레이터)

4. 앱 화면이 나타나요!

================================================================================
📱 앱 사용하기
================================================================================

1. "그늘로" 앱 화면이 보이면:
   - "출발지" 입력 (또는 그대로 두기)
   - "목적지" 입력 (또는 그대로 두기)

2. 시간 선택:
   - 09:00, 12:00, 15:00, 18:00 중 하나 클릭
   - 💡 12:00이 가장 쾌적합니다!

3. 하루 예보 확인:
   - 그래프에서 시간대별 그늘 확인

4. "쾌적한 경로 찾기" 버튼 클릭:
   - 잠깐 기다리면...
   - 지도에 경로가 나타나요!

5. 경로 정보 확인:
   - 거리
   - 소요 시간
   - 그늘 점수

6. "네비게이션 시작" 클릭 (옵션)

================================================================================
🐛 문제 해결
================================================================================

문제: "Python을 찾을 수 없습니다"
해결: Python을 설치하세요
     https://www.python.org/downloads/

문제: "Flutter를 찾을 수 없습니다"
해결: Flutter를 설치하세요
     https://flutter.dev/docs/get-started/install/windows

문제: "경로를 찾을 수 없습니다" 메시지
해결: 배치 파일의 경로를 확인하세요
     - 내 PC → 문서 → 프로젝트 폴더 우클릭
     - "주소 복사" → 배치 파일에 붙여넣기

문제: 백엔드 창이 자꾸 닫혀요
해결: 그대로 두세요 (문제 아님)
     앱이 시작되면 백엔드는 백그라운드에서 실행 중

문제: 앱이 안 켜져요
해결: 1. 백엔드를 먼저 시작했나요?
     2. 파일 경로가 맞나요?
     3. 터미널의 오류 메시지를 읽어보세요

================================================================================
💡 팁
================================================================================

- 배치 파일을 두 번 클릭하면 자동 실행 됩니다
- 검은 창이 자동으로 열려요 (놀라지 마세요!)
- 앱을 닫으려면:
  1. 앱 화면 닫기
  2. 터미널 창도 닫기

- 다시 켜려면:
  1. 백엔드시작.bat (다시 클릭)
  2. 앱시작.bat (다시 클릭)
